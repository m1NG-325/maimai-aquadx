# AquaSync 2.0 本地档案

## 使用

运行 dist/v2.0/AquaSync.exe，选择原有玩家ID，重新导入完整AquaDX JSON。旧版数据库只保存Best和最近时间，无法凭空补回逐局历史或养成资料。导入前已有的“更新本地快照”确认仍保留；本次开发验证只使用隔离目录，不覆盖用户现用资料。

新增四个入口，原有13页顺序不变：

1. 游玩历史与判定：按曲名/ID、难度、日期、新纪录筛选；按完整筛选结果排序后分页。单击查看该局封面、评级、FC/AP、达成率、DX分、连击、快慢判定、五类音符判定和当局原始字段。双击打开谱面详情。游玩日历可点击进入当日记录，判定汇总保留字段覆盖数。
2. Rating走势：DX Rating与基础Rating原始日志曲线、单曲达成率曲线、逐局变化和日志内新高；支持使用历史页筛选。原始 recent_rating_next/next_new 候选名单独立展示；参考单曲Rating采用当前统一曲库定数，不改变原始B50。
3. 冒险与养成：地图、角色、搭档亲密度、真实课程挑战记录、万华镜、登录奖励。地图同时展示通关/完成/锁定原值、最后奖励参考距离与剩余参考距离；无限地图不计算终点。课程显示次数、通关与最佳时间、最佳总达成率和DX分等独立字段，不把不同场次的最佳值拼成同一次成绩。
4. 个人档案与收藏：玩家资料和累计统计、游戏设置、选曲状态、物品与解锁、收藏项目和歌曲、对战累计与赛季排名、活动/地区/库存/角色卡/打印等其他记录。无法核实的编码按原值显示。空列表与区段未提供分别说明。

表格支持筛选、全量排序、翻页和手动CSV导出；CSV输出只包含当前筛选表格，文本首字符可能触发电子表格公式时加文本前缀。

## 名称资料

内置 data/collection_metadata.json 只包含从用户提供的游戏XML提取的名称、ID、禁用标记、地图奖励参考距离以及源文件集合哈希，不含游戏XML、程序或贴图。含修改内容的游戏目录不能证明日服/国服官方收录。

“冒险与养成→补充本地游戏名称资料”可读取自己的游戏目录，识别 Chara/Map/Course/Partner/Plate/Icon/Title/Frame/Ticket/LoginBonus/KaleidxScopeGate 等XML。按A000/Axxx补丁顺序覆盖同类同ID；名称缺失时明确显示ID。用户导入的名称快照位于所选数据目录，随数据目录迁移。

## 计算口径与隐私

- 新档案保存在现有players快照中，无需破坏式数据库迁移。旧快照缺archive时仍可查Best，新页面显示需重导；无网络自动读取、上传或同步。
- 逐局历史只覆盖本次导出保留的日志，不声称完整生涯，不合并推测未提供的对局，也不据时间间隔推算精确游玩时长。
- 日期按真实日志时间解析，展示UTC+8；先解析时间戳再按UTC+8归日，跨时区不按原始字符串截断。无时间记录保留但不画入按时间的曲线和日历。
- 判定直接汇总CriticalPerfect/Perfect/Great/Good/Miss各字段，不用于重算达成率。缺字段不是零。FAST占比=FAST/(FAST+LATE)，只使用两字段都提供的局；无快慢计数时不显示假比例。
- Rating曲线使用afterDeluxRating/afterRating对应原始字段，不混用两个体系。单曲参考Rating仍使用既有Decimal算法；“日志内新高”不等于账号历史最高。
- 卡片访问码、好友码、其他玩家昵称/用户ID、机台及打印设备序列号不写入档案。用户自身昵称、游玩地点及当局数值只留在本地；不随源码、名称元数据和EXE发布。旧Best/落雪备份/原始导出均保留。
- 物品编码与结构核对源：MewoLab/AquaDX，固定提交4a0254ec198fe0448a2682eba82f8222a233605a，src/main/java/icu/samnyan/aqua/sega/maimai2/model/userdata/UserEntities.kt；只参考协议字段及枚举事实，未复制上游实现。游戏名称/图形归SEGA及相应权利人。
- 实现：archive_data.py（白名单）、archive_analysis.py（筛选与统计）、collection_metadata.py（名称索引）、archive_widgets.py/archive_ui.py（原生表格、图表、日历与页面）。

## 2.0 历史页面调整

- 难度后增加定数列；FC/AP仅显示当局fc、fcp、ap或app状态，未达成/未提供分别表示。其他页面的FS与原始字段保留。
- 表格每页可选10、20、50、100条；筛选和排序仍作用于全部记录。更换页、筛选或排序后清空旧详情，防止左右曲目不一致。
- 当局封面/曲名、达成率/评级与FC/AP、六项指标、时间地点和判定表分区显示。常规窗口左右布局，窄窗口上下布局，可拖动分隔条；内容过多时滚动详情。
- 判定表按文字确定列宽和五行高度，左上角改为“音符\判定”，列为判定、行为音符；不转置数据。
- 各难度表格选中后保留难度底色，以提亮和边框突出选中行。
- 未实施FAST/LATE包含/排除P切换：当前导出只有总FAST/LATE和各判定总数，缺少Perfect的FAST/LATE拆分，无法准确还原两种口径。保留原始计数，不猜测。
- 由于旧EXE正在使用，本次另存AquaSync-latest.exe；启动脚本优先使用新版。用户关闭旧窗口后运行新版即可，原数据保留。

## 日历与ACC分析补充

- 单局音符判定只保留按内容大小显示的小表格，去掉外层大框；CSV和完整字段标签保留。
- 日历下方日期列表支持双击跳转，使用该行实际日期，排序/筛选后仍与点击上方日历一致。
- 日历旁新增每日游玩次数折线图，汇总当前历史筛选范围内导出保留的日志，不把缺失日期当作0；图中次数是曲目局数，不是投币次数或完整生涯出勤。
- 判定与节奏分析可勾选ACC区间，最低和最高均支持4位小数，包含两端；缺失ACC不混入指定区间。该条件只影响本页判定/快慢/FC与AP统计，不改历史列表、日历和Rating。下限大于上限时提示调整；取消勾选恢复上方历史筛选对应的全部记录。
- 分析表初始按完整表头、数字和五类音符尺寸显示；覆盖数字顺序可悬停表头查看。窗口过窄或过矮可滚动，不截断原始值。

## 日历最终布局与交付文件

每日次数折线图独占上方，下方为日历和日期列表，分隔条可调整区域大小；次数纵轴使用整数刻度，不改变Rating和ACC走势图的精度。判定分析仅有五类音符，移除每页数量和翻页控件，保留表内筛选、排序、CSV与ACC区间功能。v2.0文件夹统一使用AquaSync.exe及SHA256SUMS.txt，替换旧版与latest重名包，个人数据库不参与清理。

## Rating与单曲走势优化

- 账号Rating标签只显示账号指标选择，按全部谱面日志绘图；单曲达成率标签才显示谱面与ACC区间，避免选曲看似改变账号Rating的歧义。原始零值和下降记录不删除、不抬高或平滑，摘要说明下降次数。
- 账号Rating轴使用整数刻度；单曲ACC轴显示四位小数。悬停按屏幕二维距离定位最近点，离开点附近即隐藏提示。
- 单曲达成率支持勾选ACC最低/最高区间，包含上下限，缺失ACC不纳入指定区间；与判定页ACC条件独立。不影响账号Rating图和原始候选名单。
- 新增“单曲游玩记录”表，与谱面和ACC筛选一致。切到单曲图时自动选择该表，回账号图时回Rating变动表；原Rating变动记录与候选名单保留。
- 图与表初始空间更均衡，时间与数值列居中、曲名列加宽。曲线仅展示导出保留日志，不推断日志缺口对应的真实变化。

## 2.0 走势跳转、日期与档案图片
- Rating 变动记录和单曲游玩记录双击后，按曲目 ID 与难度选择单曲走势；排序、筛选和翻页后仍匹配原始记录。
- 走势独立日期区间同时筛选账号走势、单曲走势及其记录；可与历史页筛选叠加。未开启时显示全部日期。
- 单曲 ACC 默认启用 97%～101% 区间；可以修改或取消。账号 Rating 不受 ACC 区间影响。
- 档案缩略图来自用户提供游戏的 AssetBundleImages，依据 XML ID 和资源名匹配。开发提取工具使用 UnityPy 1.25.4 与 Pillow，运行软件不需要这些提取依赖。
- 内置 1404 个角色、27 个搭档、35 个岛屿底图、301 组课程曲绘、24 个登录奖励图片映射。地图只显示岛屿底图；课程显示 XML 中所含歌曲曲绘，不冒充官方段位徽章。
- 万华镜门图标及未匹配资源暂缺，保留文字。原游戏美术版权归各权利人；映射清单见 data/report_assets/archive/manifest.json；生成工具 tools/build_archive_images.py。
