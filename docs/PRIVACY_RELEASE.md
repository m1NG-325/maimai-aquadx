# Public distribution policy

Release source files and public metadata are collected by an explicit allowlist. Local databases, exports, backups, settings, credentials, logs, fixtures and screenshots are excluded.

Documentation uses generic filenames and usage examples. Actual player identities, local machine paths, score values and aggregate player statistics are excluded. Public song metadata and artwork retain their original source attributions.

A clean installation starts with no players or scores. Data imported by a user is stored in that user's selected local directory. Connecting a remote account does not publish that account's data to this source repository.
