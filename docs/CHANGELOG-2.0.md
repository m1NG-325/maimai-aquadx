# AquaSync 2.0

在1.2基础上新增完整本地档案查询，保留既有B50、牌子、曲库、推荐、计算、目录迁移及手动落雪同步。

- 游玩历史：逐局日志、全量筛选排序与分页、日历、单曲当局详情、CSV导出。
- 判定分析：TAP/HOLD/SLIDE/TOUCH/BREAK各判定、FAST/LATE及覆盖数；区分零与缺失。
- Rating走势：原始DX/基础Rating曲线、单曲达成率、逐局增减与原始候选名单。
- 冒险与养成：地图、角色、搭档、实际段位课程挑战、万华镜、登录奖励。
- 个人档案：资料累计、操作设置、选曲状态、收藏歌曲与物品、解锁、对战及赛季、活动与地区等记录。
- 名称补全：内置角色/地图/称号等游戏XML名称快照，也可读取用户选择的本地游戏资料目录；未知名称保留ID。
- 本地隐私：显式字段白名单，不存访问码、其他玩家身份或机台序列号；名称索引与EXE不包含个人档案。
- 兼容旧版数据库。完整新功能需要重新导入完整JSON，旧快照无法恢复原本未保存的日志。

详细口径与使用见ARCHIVE-2.0.md。运行dist/v2.0/AquaSync.exe。本次不改README、不上传GitHub、不操作Releases。

历史页布局修订：FC/AP状态、定数列、10/20/50/100条分页、独立指标卡与完整判定表；选中曲目保留难度底色，窄窗上下分区。FAST/LATE含/不含P开关因导出缺少Perfect快慢拆分暂不实现，继续显示原始计数。
