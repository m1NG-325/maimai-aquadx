# AquaSync 桌面版

2026-10-15 更新：桌面使用半透明蓝灰面板、圆角和柔和背景，成绩/曲库/推分表格显示封面。B50 默认「整图适应窗口」，同时按可用宽高计算等比例缩放，完整显示 B35+B15；取消勾选可回到放大滚动浏览，导出仍为 1280 宽完整图。

已内置公开曲绘，可离线查看已有资源。未核实的曲目或封面显示占位信息，不错配其他歌曲。

图鉴样式更新：B50 为五列曲绘卡片，使用难度配色和 FC/FS/评级徽章；牌子完成表按等级排列曲绘，已完成项显示浅色覆盖和绿色勾。选择版本、牌子、难度或「只看未完成」，可以导出整张 1280 像素宽 PNG。总览表仍可通过按钮展开。

已附带 1702 张公开曲绘；三个牌子范围的曲绘仅历史ID444暂无可核实图片，显示占位；额外曲目点击「更新当前图鉴曲绘」即可缓存在数据目录的 `covers` 文件夹，网络请求只发送歌曲 ID。查询和已有曲绘展示可离线使用。单曲 Rating 按参考定数计算，不能核实定数的谱面显示待核实。

双击 `AquaSync.exe`，直接在 Windows 窗口使用。无需安装 Python，不启动浏览器，也不监听本地 HTTP 端口。

第一次使用：点击「导入 AquaDX JSON」，选择私服导出的文件；填写本地玩家 ID 后加载。已有玩家再次导入会提示更新本地快照。查 B50、成绩、牌子、曲库、随机选曲和计算器无需联网。

默认数据目录为 `%LOCALAPPDATA%\AquaSync`，包含 SQLite 成绩、公共曲库缓存和落雪备份。EXE 不打包用户成绩、备份、API 密钥或测试样本。

可以指定数据目录：

```powershell
.\AquaSync.exe --data-dir ".\AquaSyncData"
```

桌面功能：

- B50 卡片与 PNG 导出，私服原始 / 本地估算 / 落雪估算 / 旧版 B40 估算。
- 双 B50 按同一谱面对齐；落雪账号侧先读取成绩并备份。
- 全成绩筛选、完整 JSON 导出、单曲所有难度成绩。
- 牌子进度从旧到新，双击进度显示未完成谱面。
- 曲库按曲名/ID、类型、难度、定数范围查询，随机选曲。
- 推分推荐、Rating 计算、FC/AP/FS 统计。
- 文字猜歌、开字母、今日舞萌。
- 分数线容错、条件完成表、自选 Best 列表、30 项段位配置。
- 落雪密钥连接、原成绩备份、选择差异、降低字段确认、提交前再次校验、回读核对和备份导出。网络请求在后台线程执行，查询不自动上传。

日服定数和段位配置只作参考；无法确认私服实际定数、删曲范围和段位通过情况。未知曲名或缺失定数保持待核实，不以显示等级代替精确定数。不能使落雪网站新增未收录谱面。

现有功能对照见 `KARENBOT_FEATURES.md`，算法与数据来源见 `ALGORITHMS_AND_SOURCES.md`，软件内也可直接阅读。

从源码运行 / 打包：

完整包中的封面保存在 EXE 内，避免重复占用压缩包空间。安装构建依赖后，如源码目录尚无 `data/report_assets`，可运行 `python tools/extract_report_assets.py ../AquaSync.exe data/report_assets` 提取公开资源，再运行下述打包命令。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe desktop.py
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm AquaSync.spec
```

`start-desktop.bat` 优先启动 EXE，找不到时用本地 Python 环境运行桌面版。兼容 CLI / API 模块不是桌面版的运行依赖。

谱面详情在 B50 页面右侧以页签打开，支持多个非模态详情并存；可拖动单个标签页到标签栏外，松开后成为独立窗口，也可重新停靠。停靠详情只在 B50 页面显示，切到其他页面会隐藏，返回时恢复；已拖出的独立详情保持可用。其他页面点击曲目会直接打开独立详情。详情显示封面、各难度达成率、评级图标、单曲 Rating、FC / FS、DX 分及元数据来源。

当前版本位于 `dist/v1.1/AquaSync.exe`；`start-desktop.bat` 优先启动 1.1。完整包内直接运行根目录的 AquaSync.exe。

B50 卡片的达成率位于彩色区内，定数 / 单曲 Rating、评级和 FC/FS 图标对齐白条中线；DX/标准标识使用原生矢量绘制。双 B50 私服数据为浅蓝色，落雪数据为金色，估算和已有账号两种模式使用相同配色。

## 1.0 列排序

曲库和推分推荐的所有表头显示上下三角，当前排序方向高亮。点击列名切换升降序；定数、达成率、Rating 与收益按数值，版本按发布时间顺序。排序不影响封面或双击打开的谱面；更改筛选后保留排序。未知定数和未玩项升序置前、降序置后。

## 1.0.1 牌子曲库

默认「完整私服参考曲库」按谱面 ID 与难度合并日服参考库和原分析库，参考数据优先，分析库补缺；因此包含参考库已收录的 DX PLUS、CiRCLE、CiRCLE PLUS、MAGiCAL 等版本。仅列出有谱面数据的版本，不为未收录版本编造空进度。

版本列表、总览分母、完成数、未完成清单和完成表图片使用同一份曲库。可切换「原分析曲库」查看旧口径；不改变 B50、原始成绩或落雪可上传资格。真 / 舞及 Re:MASTER 规则保持原样。

这些是参考曲库内的完成进度，不代表私服曲库绝对完整，也不表示官服授牌。来源和地区差异仍以对应服务器为准。


牌子进度现有三个选项：私服曲库（日服现行）、国服曲库（可怜 bot 国服完成表）、私服曲库（含删除曲目）。切换时总览、缺失清单、图片及单曲详情一起切换；不改变 B50 或落雪上传范围。详细来源及历史曲处理见 PLATE_CATALOGS.md。

版本名称统一为 maimai MiLK PLUS，旧名称仍可读取。含删除曲目范围的“真”已逐项核对：106首、424张BASIC～MASTER；详情见 TRUE_PLATE_AUDIT.md。

Rating 计算页现为原生彩色对照表，默认展示定数12.0～15.0，可调整范围；小字表示同评级内再增加1分所需达成率，大字表示单曲Rating。点击格子联动下方计算器，输入仍可手动修改。窗口较小时支持横向、纵向滚动。此次改动仍使用1.1版本号；本地新版位于 `dist/rating-table/AquaSync.exe`，启动器优先打开该版本。

推分推荐新增「私服 / 国服」切换。私服使用完整日服历史参考与私服补充定数，可选择新曲版本，优先从导出新曲名单识别；识别不唯一时明确提示核对。国服使用落雪当前国服曲库的定数与年度版本分组。两个模式均基于当前本地导入成绩，不代表已读取官服账号。各自显示B35/B15门槛、缺定数与未匹配数量，保留列排序。最新本地软件为 `dist/recommend-scopes/AquaSync.exe`。

统一曲库更新：成绩查询、B50、曲库/随机选曲、详情、推分推荐、条件完成表共用 `app/unified_catalog.py`，牌子仍使用各地区的原始要求清单，但同一地区同一版本的曲名、定数和物量等字段从统一索引解析。曲库页面可切换全部/私服/国服。使用新软件加载已有玩家即可补齐元数据，不需重新导入成绩；原始成绩及B50原报总分保留，估算结果可能因补全而变化。最新本地EXE为 `dist/unified-catalog/AquaSync.exe`。

成绩查询卡片更新：保留每行两首，大窗口卡片行高112，小窗口132；宽屏将定数、DX分和游玩次数横向置于中部，达成率和Rating置右。增加难度色条、评级及FC/FS图标、独立单卡选中；窄窗口自动重新排版。最新本地软件为 `dist/score-cards/AquaSync.exe`。

成绩查询新增八种排序：最近游玩、定数、DX分、游玩次数、达成率、Rating、FC状态及AP状态，各支持升降序，未知值统一放末尾。默认仍为达成率降序。此页为导出中保留的每张已玩谱面最佳快照，达成率、DX分、FC/AP和最近时间可来自不同局，并非完整逐局历史。最近游玩时间优先关联同musicId+难度的userPlaylogList.userPlayDate等真实字段，只能表示导出所保留记录中的最近一次。旧快照需要重新导入完整JSON；没有时间时显示未提供。无时区日期按UTC+8解析，展示为UTC+8。

难度色条已改为半透明卡片底色。D～SSS+评级统一替换为mai-kit公开资源中固定提交的256×120原始透明PNG，支持高DPI绘制，成绩页、详情和B50共用；详见rank_manifest.json和MaiKit-Assets-LICENSE.txt。最新本地EXE为 `dist/v1.1/AquaSync-latest.exe`。


界面与图标更新：成绩查询的评级图标紧跟 ACC 数值，图标高度随 ACC 字号自适应；宽卡片将评级与 Rating 数字留出独立空间，窄卡片自动缩小避免挤压。B50 白条中的评级框从30×15调整到40×18并保持上下间隔。FC/AP/FS全状态共用80×80原始透明PNG。曲库、推分推荐和段位表使用与成绩卡片一致的半透明难度底色；排序仍保留曲绘和谱面身份。段位表四首配置歌全部增加曲绘，双击可打开软件内详情。段位随机配置仍由游戏实际选曲，不额外猜测曲目。
