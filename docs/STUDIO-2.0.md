# AquaSync Studio 2.0

独立的界面试用版本，功能与当前 AquaSync 2.0 一致。运行 dist/v2.0-studio/AquaSync-Studio.exe；原版 dist/v2.0/AquaSync.exe 保留。

- 深石墨背景、浅蓝强调色，减少装饰性渐变。
- 收紧侧栏导航，统一字号、标题层级与页面间距。
- 统一按钮、输入框、日期选择、勾选框与滚动条。
- 表格减少网格线，标签页使用下划线选中状态；保留难度底色。
- 共用原来的数据目录和设置，不另复制个人数据。

实现入口 desktop_studio.py，样式 app/studio_theme.py，打包配置 AquaSync-Studio.spec；标准 desktop.py 的样式不变。

## 2.0 成绩统计概览
- 顶部四张指标卡：已玩最佳谱面、累计游玩次数、FC 及以上、AP 及以上，并显示完成占比。
- 评级横条分布、FC/AP 环形分布、各难度表现、标准/DX/特殊谱面概况与同步标记。
- 所有图表只统计导入的最佳成绩；不把谱面占比称为全曲库完成率。平均达成率排除未知值；未知成绩与特殊难度独立保留。
- 宽屏两列、窄屏单列滚动；保留 Studio 视觉样式及当前 2.0 版本。

## 2.0 段位定数、导航与地图详情
- 段位表在难度后增加定数；按谱面 ID 与难度从统一参考曲库读取，未知标为待核实。
- “功能与数据说明”移到左侧最后；内部页面 ID 保持稳定，show_page 与命令行自检按原页面 ID 定位。
- 角色表除名称列外全部居中。
- 双击地图在冒险页内部打开详情标签，可多开、切换、关闭；显示原报距离和状态、参考距离、开放条件编码、加成曲组及奖励/解禁节点。达到距离不等于实际领取。
- 从本地 XML 核对 226 张地图，205 张含名牌板奖励且对应图片全部匹配；21 张未收录名牌板奖励，保留无图状态。地图图像统一选路线距离最后的名牌板奖励，不使用岛屿底图替代。
- 公共参考元数据 data/map_details.json；提取工具 tools/build_map_details.py；原游戏内容与美术权利归各权利人。

## 2.0 地图奖励图片与推荐列布局
- 奖励 / 解禁要素列新增角色、名牌板底板、背景框、头像原图；曲目解禁与任务曲目显示曲绘；挑战解禁根据 Challenge.xml 的 Music/id 显示关联曲绘，不使用挑战 ID 推测。
- 本地路线中相关 2625 个节点全部匹配图片；称号、仅数值礼物等无独立图片的项目保留文字。达到距离仍不等于实际领取。
- 推分推荐在曲目后新增独立难度列，曲目左对齐，其余列全部居中；保留难度色、两种口径颜色、曲绘与各列排序，曲目列可调整宽度。

## 2.0 课程挑战与登录奖励
- 固定课程列表显示对应曲绘组合，双击可在软件内查看四首曲绘、难度、统一参考定数、各谱面最佳成绩及课程配置/通关统计。单曲最佳不冒充此次课程逐曲成绩。
- 324 个课程配置中 239 个固定课程的 956 个曲目位置均有曲绘；85 个随机课程明确标为随机，不显示占位曲目作为真实选曲。
- 登录奖励新增类型与所需点数，72 种奖励全部匹配搭档、曲目、背景框、名牌板、头像或票券图片。票券图通过 Ticket.xml filename 精确关联原始 Sprite。
- 双击登录奖励显示软件内详情，包括奖励图片、内容、点数、完成状态、重复领取配置与开放事件；状态按导出保留，不根据点数猜测实际领奖。
- 本地元数据为 data/activity_details.json，构建工具 tools/build_activity_details.py；均不含玩家成绩。补充本地 XML 时同时更新课程与奖励参考资料。
