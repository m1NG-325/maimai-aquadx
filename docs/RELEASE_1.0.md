# AquaSync 1.0

Windows 本地舞萌查分软件，直接运行 AquaSync.exe，无需 Python 或浏览器。

- AquaDX JSON 导入、完整成绩查询、B50、双 B50 对比与牌子进度。
- 曲库和推分推荐支持逐列升降序，表头上下三角与当前方向高亮；数值按真实数值、版本按时间排序。
- 曲库类型、难度、定数与关键词自动筛选；排序不影响封面和打开的谱面。
- 多谱面详情、半透明界面、报表适应窗口、滚轮缩放和拖动。
- 可更改数据目录并自动迁移与校验，原目录保留。
- 落雪成绩读取、备份、差异选择上传和回读核对；水鱼/落雪 JSON 导出。
- 功能与数据说明列明算法、数据和参考源码来源。

下载 AquaSync.exe 即可使用。AquaSync-v1.0-source.zip 提供源码、公开参考数据和构建说明；曲绘与报表素材已在 EXE 内，可按文档提取用于构建。SHA256SUMS.txt 用于核对文件完整性。

公开参考定数、新旧曲划分与私服版本可能不同；原报总分和参考计算分别展示。未核实信息保留待核实状态。落雪上传前请核对账号；备份不会在远端隔离官服与私服成绩。
