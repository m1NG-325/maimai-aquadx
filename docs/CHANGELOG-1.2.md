# AquaSync 1.2

与正式版1.1相比，包含其后完成的以下更新：

- 统一曲库：成绩查询、B50、曲库、详情及推分推荐共用元数据；牌子保留各地区要求清单，曲名与定数通过共享曲库解析。补齐此前仅在牌子参考曲库中出现的谱面。缺失或无法核实的资料仍显示待补充，不猜测。
- 推分推荐区分私服与国服：分别采用对应曲库、定数及新旧曲分组；私服支持选择新曲版本，并展示推荐门槛和缺定数数量。两种模式均使用本地导入成绩，国服模式不等于已读取官服账号。
- Rating计算新增彩色定数×达成率对照表：可调整定数范围，并显示同评级内再增加1分所需的最低达成率；保留单次计算器。
- 成绩查询改为紧凑的每行两首卡片：减少留白，突出封面、曲名、达成率、定数、单曲Rating、DX分和次数；大小窗口自动布局，支持单卡选择和软件内详情。
- 成绩查询新增八类双向排序：最近游玩、定数、DX分、游玩次数、达成率、Rating、FC、AP。未知值统一置后。最近时间来自导出中的真实字段或保留的游玩日志；旧快照需要重新导入完整JSON，缺时间不推测。查询页展示导出保留的各谱面Best，并非完整逐局历史。
- 视觉统一：成绩、曲库、段位表、推分推荐以难度作为半透明底色；保留私服与国服的字体颜色区分。修复Qt主题遮盖底色的问题。
- 高清图标：D～SSS+评级采用256×120原始透明PNG；FC/AP/FS等状态采用80×80原图，支持高DPI。成绩页评级紧跟ACC且高度随字号调整；B50评级放大并修复白条内间距和边界。
- 段位表全部配置曲目增加曲绘，可双击打开软件内详情。
- 功能与数据说明补充共享曲库、时间与排序、评级/状态素材的来源、许可及核验信息。

本次1.2定版仅更新统一版本号与本地启动器，以上功能已在此前迭代完成。保持现有数据目录和数据库兼容；原始成绩及私服B50原报总分保留，参考估算可随统一元数据变化。README未修改，也未操作GitHub或Release。

运行：dist/v1.2/AquaSync.exe。仅需EXE即可运行，不需要Python或网页。
