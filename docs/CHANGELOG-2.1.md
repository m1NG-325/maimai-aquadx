# AquaSync 2.1 更新日志

- 新增落雪 CSV 成绩导入，支持成绩查询、B50 估算和牌子进度。
- 保留 CSV 中的达成率、DX 分、FC/FS 和有效游玩时间，重复谱面按最佳成绩合并。
- 优化落雪同步表格：表头和文字居中，「选择」列收窄。
- 精简未使用的运行依赖，运行依赖与资源目录相比 2.0 减少约 65.7 MiB，图片素材和画质保持不变。

继续提供 Windows 10/11 x64 安装版与便携版，无需安装 Python。

落雪 CSV 不含完整玩家档案、原始 B50 分组和游玩日志，建议使用独立本地玩家 ID 导入。更新前关闭程序，保留 `user-data` 和 `AquaSync-desktop.json`。
