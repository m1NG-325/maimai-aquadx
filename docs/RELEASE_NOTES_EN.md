# AquaSync — English release notes

[English README](../readme_EN.md) · [中文 README](../README.md) · [GitHub Releases](https://github.com/m1NG-325/maimai-aquadx/releases)

These notes provide English versions of the existing release descriptions. They do not create or replace a GitHub Release or its attachments.

## [2.0](https://github.com/m1NG-325/maimai-aquadx/releases/tag/v2.0)

- Added individual play logs, a play calendar, daily play-count trends and judgement analysis.
- Added Rating and single-chart achievement trends, with date and achievement-range filtering.
- Added map rewards, characters, partner intimacy, course challenges, Kaleidx Scope, login bonuses and player collections.
- Adopted the Studio interface and improved artwork, statistics, song guessing and advanced tool layouts.

Download either `AquaSync-2.0-Setup.exe` to install or `AquaSync-2.0-Portable.zip` to extract and run. Reimport a complete AquaDX JSON export to use the additional archive features. Missing export fields cannot be reconstructed.

## [1.2](https://github.com/m1NG-325/maimai-aquadx/releases/tag/v1.2)

- Unified song metadata across pages and filled in missing titles and reference chart constants.
- Separated private-server and Chinese-server improvement recommendations.
- Added a colored Rating reference table.
- Improved score cards and reduced unused space.
- Added sorting by latest play, chart constant, DX score, play count, achievement, Rating, FC and AP.
- Unified difficulty backgrounds and upgraded rank and FC/AP/FS icons.
- Added jackets to course tables, with double-click access to song details.

## [1.1](https://github.com/m1NG-325/maimai-aquadx/releases/tag/v1.1)

- Expanded plate completion tables and separated Chinese-server, private-server and removed-song reference scopes.
- Added songs missing from version 1.0.
- Added song metadata and 176 jackets.

## [1.0](https://github.com/m1NG-325/maimai-aquadx/releases/tag/v1.0)

A local Windows desktop app. Download and run `AquaSync.exe`; Python and a browser are not required.

- B50, dual B50 comparison, plate completion tables, score search and a song library.
- Improvement recommendations, Rating calculation, column sorting and report zooming.
- LXNS score backups and selected-difference synchronization.
- Data-directory selection and automatic migration.

Public reference chart constants can differ from private-server values. Check the destination account before syncing to LXNS.
