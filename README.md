# AquaSync 1.2

Windows 本地舞萌查分软件，支持导入 AquaDX 私服导出的 maimai2 JSON，查看成绩、B50、牌子进度和推分推荐。

## 使用

1. 在本仓库 **Releases** 下载 `AquaSync.exe`，双击运行
2. 点击「导入 AquaDX JSON」，选择成绩文件
3. 查看 B50、成绩、牌子进度或推分推荐

## 功能

- B50 展示、双 B50 对比与图片导出
- 成绩查询、搜索和八类排序
- 国服、私服及含删除曲目的牌子参考曲库
- 曲库查询、筛选、排序与随机选曲
- 私服与国服分别计算的推分推荐
- Rating 彩色对照表与计算器
- 段位表、曲绘及谱面详情
- 落雪成绩备份、差异对比与选择上传
- 自定义数据目录与数据迁移
