# AquaSync 1.1

Windows 本地舞萌查分软件，支持导入 AquaDX 导出的 maimai2 JSON

## 使用

1. 在本仓库 **Releases** 下载 `AquaSync.exe`，双击运行
2. 点击「导入 AquaDX JSON」，选择成绩文件
3. 查看 B50、成绩、牌子进度或推分推荐

## 功能

- B50 与双 B50 对比、牌子完成表、成绩及曲库查询
- 牌子支持私服曲库、国服曲库、私服曲库（含删除曲目）
- Rating 计算、推分推荐、FC/AP/FS 统计
- 落雪成绩备份、差异选择同步，水鱼/落雪 JSON 导出
- 可更改数据目录并自动迁移；成绩保存在本机

公开参考定数可能与私服不同，落雪同步前请核对目标账号
